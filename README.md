# 订单履约控制塔

## 备份方式

使用 Git + GitHub 进行版本管理。

**备份仓库**: [github.com/Laooma/order-fulfillment-tower](https://github.com/Laooma/order-fulfillment-tower)

## 拉取项目

```bash
git clone https://github.com/Laooma/order-fulfillment-tower.git
cd order-fulfillment-tower
```

## 日常备份

```bash
git add .
git commit -m "描述本次改动"
git push
```

## 本地历史备份

项目根目录下 `历史备份/` 保留了关键节点的备份快照，用于在 AI 改坏代码时快速还原。
